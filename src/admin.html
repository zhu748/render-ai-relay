怎么定位这次 126 秒错误

  1. 连接后台后，在客户端再次发起一次非流式请求。
  2. 完全没有对应记录：检查客户端请求地址，或网页是否使用原域名直接请求接口。
  3. 有记录，心跳次数持续增加，目标站却报错：检查目标站内部访问 AI 上游的连接。Render 的心跳无法修复另一段连接的断开。
  4. 记录出现错误：查看上游 HTTP、阶段和错误码。也可在 Render → 当前服务 → Logs 中按完整请求 ID 搜索。
